About This Project

Anomaly Detection using Machine Learning — LPU Edu Revolution Submission

🎯 Problem Statement

In large-scale systems such as industrial machinery, financial transactions, and network traffic, manually identifying abnormal patterns is infeasible at scale. Traditional threshold-based rules fail to capture complex multi-variate anomalies.

This project provides an automated, ML-driven pipeline that can detect anomalies in any tabular CSV dataset without requiring labelled training data (unsupervised learning).
