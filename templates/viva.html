🗣️ 60-Second Project Introduction Script
"My project is an Anomaly Detection System built using Python and Flask. It allows users to upload any CSV dataset, select numeric feature columns, and automatically detect anomalies using unsupervised machine learning algorithms like Isolation Forest, One-Class SVM, and Local Outlier Factor. The system preprocesses the data using StandardScaler, trains the model, and outputs each record labelled as Normal or Anomaly. It also generates interactive charts — scatter plots, line charts, pie charts, and histograms — to help visualise the results. The final labelled CSV can be downloaded for further analysis. I built this to demonstrate real-world applications of ML in fields like predictive maintenance, fraud detection, and network security."

What is anomaly detection? ▼
Anomaly detection (also called outlier detection) is the process of identifying data points, events, or observations that deviate significantly from the expected behaviour of a dataset. These deviations are called anomalies or outliers. It is used in fraud detection, network intrusion detection, industrial fault detection, medical diagnosis, and more.
What is Isolation Forest and why did you choose it? ▼
Isolation Forest is an unsupervised ML algorithm introduced by Liu et al. (2008). It works on the principle that anomalies are "few and different" — they are easier to isolate in a random tree structure. The algorithm builds an ensemble of isolation trees; anomalies require fewer splits to be isolated, resulting in a shorter average path length. It assigns an anomaly score based on this path length. I chose it because:
  • It is efficient on large, high-dimensional datasets (O(n log n)).
  • It does not require a distance or density measure.
  • It handles mixed-type features well with a contamination parameter.
  • It is the industry standard for general-purpose anomaly detection.
What is the contamination parameter? ▼
The contamination parameter tells the algorithm the expected proportion of anomalies in the dataset. For example, contamination=0.05 means we expect 5% of records to be anomalies. The model uses this to set the decision threshold on the anomaly score. If you do not know the exact proportion, 0.05 is a safe default for most real-world datasets.
Why do you use StandardScaler? ▼
StandardScaler transforms each feature to have zero mean and unit variance. This is important because:
  • Features with large value ranges (e.g. Pressure: 80–200) can dominate those with small ranges (e.g. Vibration: 0.1–3.0).
  • While Isolation Forest is scale-invariant for a single feature, multi-feature detection benefits from normalisation.
  • One-Class SVM and LOF are explicitly distance/density-based and require scaling.
What does the output -1 and 1 mean? ▼
Scikit-learn's convention for anomaly detection models:
  • 1 = Normal (inlier) — the data point fits the expected distribution.
  • -1 = Anomaly (outlier) — the data point deviates significantly from the normal pattern.
In the output CSV, the Prediction column stores these raw values, and the Status column converts them to the human-readable "Normal" / "Anomaly" labels.
What are the real-world applications of anomaly detection? ▼
  • Predictive Maintenance — Detect sensor anomalies in machinery before equipment failure.
  • Fraud Detection — Flag unusual credit card transactions or bank transfers.
  • Network Security — Identify unusual traffic patterns suggesting a cyber attack.
  • Healthcare — Detect abnormal patient vitals (heart rate, blood pressure).
  • E-Commerce — Spot fake reviews, bot traffic, or unusual purchase behaviour.
  • Quality Control — Identify defective products on a manufacturing line.
How does Local Outlier Factor (LOF) work? ▼
LOF compares the local density of a data point to the density of its k nearest neighbours. A point with a much lower density than its neighbours (LOF score > 1) is considered an outlier. It is density-based and effective when anomalies form clusters or when the data has varying density regions. It is computationally more expensive than Isolation Forest for large datasets.
How does One-Class SVM work? ▼
One-Class SVM learns a decision boundary that encloses the "normal" region of the feature space using a kernel function (usually RBF). Any point outside this boundary is labelled an anomaly. The nu parameter controls the upper bound on the fraction of training errors and the lower bound on the support vector fraction. It works best on small to medium datasets where the normal class is well-defined.
What is the project workflow? ▼
  1. User uploads a CSV via the upload page.
  2. data_handler.py validates the file, loads it into a Pandas DataFrame, and detects numeric columns.
  3. A dataset preview (first 8 rows) is shown on the dashboard.
  4. User selects feature columns, algorithm, and contamination rate.
  5. detector.py applies StandardScaler, trains the selected model, and generates predictions and anomaly scores.
  6. Results are stored in Flask session and the labelled CSV is saved to data/processed/.
  7. Charts (scatter, line, pie, histogram) are built using Chart.js with JSON data from Flask routes.
  8. User downloads the output CSV.
What improvements could be made to this project? ▼
  • Add deep learning models (Autoencoder, LSTM) for time-series anomaly detection.
  • Integrate real-time streaming with WebSockets or Kafka.
  • Add user authentication and a history/dashboard for multiple runs.
  • Use a database (SQLite/PostgreSQL) to persist results across sessions.
  • Expose a REST API for integration with IoT platforms or dashboards like Grafana.
  • Add SHAP-based feature importance to explain why a record is flagged as anomalous.
