How It Works
Four steps from raw data to labelled anomaly output

1 · Upload CSV Dataset

Drag and drop any CSV file. The system auto-detects numeric columns and shows a preview.

2 · Configure Detection

Select feature columns, choose an algorithm (Isolation Forest, One-Class SVM, or LOF), and set contamination ratio.

3 · Run & Visualise

Model trains on scaled features. Results are shown instantly with scatter, line, pie, and distribution charts.

4 · Download Output

Get the original data enriched with Prediction (-1/1) and Status (Anomaly/Normal) columns.
